# snippets 目录说明

目录包含三个已存在的 snippet 集合（`research_templates.code-snippets`, `research_short.code-snippets`, `research_micro.code-snippets`）。

目的：
- `research_templates`: 完整模板（详尽、带说明），适合生成长格式输出。
- `research_short`: 短版模板，节省 token，适合集成到快速对话或循环中。
- `research_micro`: 微型代码片段，用作构建块或粘贴入脚本中。

同步说明：如果你希望把这些 snippet 应用到 VS Code 用户配置，请将文件复制到：
`C:\Users\hqh\AppData\Roaming\Code\User\snippets\`。

维护建议：定期审查 `research_*` 文件，保留常用的微模板至 `prompts/08_micro_templates.md` 以便快速引用。
