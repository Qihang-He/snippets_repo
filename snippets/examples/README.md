# 示例脚本

位置：`snippets/examples/`

包含示例：

- `data_analysis_example.py`：生成示例 CSV，计算分组统计并保存箱线图（dpi=300）。
- `figure_example.py`：绘制 publication-ready 折线图并保存高清图片。
- `latex_table_example.py`：生成最小 LaTeX 表格片段并保存为 `.tex` 文件。
- `requirements.txt`：运行这些示例所需的最小依赖列表。

运行示例：

```powershell
python snippets/examples/data_analysis_example.py
python snippets/examples/figure_example.py
python snippets/examples/latex_table_example.py
```
