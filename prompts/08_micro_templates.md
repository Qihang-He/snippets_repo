# 微型模板（Micro templates / Code snippets）

包含常用的小代码片段，便于粘贴到脚本中以节省 tokens：

- `micro:load`：加载并预处理数据（pandas，缺失值处理，类型转换）。
- `micro:savefig`：保存高质量图片的最小代码块。
- `micro:ttest`：配对 t 检验（scipy）简短示例。
- `micro:reg`：简单线性回归（statsmodels）并打印摘要。
- `micro:ltx_table`：LaTeX 表格最小示例。
- `micro:bib`：最小 BibTeX 条目。
- `micro:reqs`：`requirements.txt` 最小示例。
- `micro:run`：脚本的 `__main__` 最小运行段。

建议：在需要节省上下文长度时，优先使用这些微型模板作为构建块。
